Privacy & data use

Privacy Policy

Effective date: November 11, 2026

This policy explains how TrakCare Mac Watchdog (the “Utility”), a privately operated macOS utility, is designed to access and use information from a dedicated Gmail account. The Utility is intended for use only by its authorized operator.

1. Information accessed

With the operator's Google authorization, the Utility requests the Gmail read-only scope (https://www.googleapis.com/auth/gmail.readonly). That permission can allow it to list and read messages in the authorized Gmail account. The intended implementation narrows processing to messages associated with authentication and connection recovery. Gmail read-only access does not authorize modifying, sending, or deleting messages.

2. Purpose and use

The Utility uses Gmail access solely to recognize recently received verification messages relevant to an authorized sign-in workflow and, where configured and permitted, use the relevant code in that authentication flow. It may use message sender, subject, timestamp and body to distinguish a current code from an older one. This use is limited to the operator's own authorized access.

3. Storage and retention

The Utility is designed to run locally on the operator's Mac. OAuth authorization files are stored in a restricted local directory and should be protected using macOS file permissions and device security. Verification codes should be processed transiently and should not be written into diagnostic logs or retained after their immediate use. The operator can revoke Google's authorization and delete local OAuth files.

4. Sharing and transfers

The public website does not receive Gmail data. The Utility is not intended to sell Gmail data, use it for advertising, or transmit mailbox contents to an external analytics service. When a code is used for an authorized sign-in, that code is supplied to the relevant authentication service as part of the requested login. Gmail API requests are processed by Google as necessary to provide the API.

5. Security

Safeguards are intended to include Google OAuth authorization, least-privilege API scopes, restricted local credentials, limited authentication retries, and logs that exclude message bodies and verification codes. The security of the Mac, Google account, forwarding device and healthcare-system account remains important.

6. Google API Services User Data Policy

The intended use and transfer of information received from Google APIs is limited to providing the functionality described above and is subject to the Google API Services User Data Policy, including its Limited Use requirements where applicable.

7. User control and deletion

The account holder can revoke the Utility's Google access in their Google Account connections. Local token and credential files can then be deleted from the Mac. Messages already present in Gmail remain under the account holder's control through Gmail.

8. Changes and contact

This policy may be updated if the Utility's actual functionality or data practices change. For questions, privacy inquiries, or requests about local data, contact secretaria.dr.chaparro@gmail.com.

This is an independent utility, not an official product of any hospital or the third-party services used for authentication or connectivity.
