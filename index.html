TrakCare Mac Watchdog

TrakCare Mac Watchdog is a privately operated utility for a dedicated macOS computer. Its purpose is to monitor connectivity to authorized remote clinical systems and help restore interrupted connections using the institution's approved authentication process.

Gmail integration

The utility is designed to use the Gmail API with read-only permission to identify relevant, newly received authentication messages in a dedicated mailbox. Any Gmail integration runs locally on the authorized Mac; the website you are reading does not connect to Gmail, collect email, or perform authentication.

Availability

This is an internal, single-operator tool. There is no public sign-up, hosted service, or product for third-party users. This site provides information about its intended operation and privacy practices.
